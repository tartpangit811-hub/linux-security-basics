# Network Security Basics

## Introduction

Network security is the practice of protecting computer networks, devices, and data from unauthorized access, attacks, and misuse.

A secure network helps maintain confidentiality, integrity, and availability of information.

---

# 1. Importance of Network Security

Network security helps to:

- Prevent unauthorized access
- Protect sensitive data
- Reduce cyber threats
- Maintain reliable communication
- Protect connected devices

---

# 2. Common Network Threats

## Malware

Malicious software that can damage systems or steal information.

Examples:

- Viruses
- Trojans
- Ransomware

---

## Unauthorized Access

Occurs when attackers gain access without permission.

Causes:

- Weak passwords
- Poor security settings
- Stolen credentials

---

## Denial of Service (DoS)

An attack that attempts to make services unavailable by overwhelming network resources.

---

## Man-in-the-Middle Attack

An attacker secretly intercepts communication between two systems.

---

# 3. Network Security Controls

## Firewall

A security device that filters incoming and outgoing network traffic.

Functions:

- Block unauthorized connections
- Allow trusted traffic
- Monitor network activity

---

## Network Segmentation

Dividing a network into smaller sections.

Benefits:

- Limits attack spread
- Improves security control
- Separates critical systems

---

## Access Control

Controls who can connect to network resources.

Examples:

- User authentication
- Permission management
- Device authorization

---

# 4. Secure Network Configuration

Best practices:

- Change default passwords
- Disable unused services
- Update firmware regularly
- Use secure protocols
- Configure firewalls properly

---

# 5. Wireless Network Security

Protect Wi-Fi networks by:

- Using strong passwords
- Enabling WPA2/WPA3 encryption
- Changing default router settings
- Monitoring connected devices

---

# 6. Network Monitoring

Monitor:

- Network traffic
- Connected devices
- Security alerts
- Unusual activities

---

# 7. Secure Communication

Use secure protocols:

- HTTPS
- SSH
- VPN
- Encrypted connections

---

# 8. Network Security Best Practices

Follow these practices:

- Keep devices updated
- Use strong authentication
- Monitor network activity
- Backup configurations
- Limit user access

---

# Conclusion

Network security is essential for protecting systems, users, and data from cyber threats.

Proper configuration, monitoring, and security controls help create a safe and reliable network environment.
