# Monitoring and Logging

## Introduction

System monitoring and logging are important security practices used to track system performance, detect problems, and identify suspicious activities.

Logs provide information about what happened inside a system and help administrators investigate security incidents.

---

# 1. System Monitoring

System monitoring checks the health and performance of devices and services.

Monitor:

- CPU usage
- Memory usage
- Disk space
- Network traffic
- Running services
- System uptime

---

# 2. Security Monitoring

Security monitoring helps detect possible threats.

Check for:

- Unauthorized login attempts
- Suspicious network connections
- Malware activity
- Unusual user behavior
- Failed authentication attempts

---

# 3. Understanding Logs

Logs are records created by systems and applications.

Common log types:

## System Logs

Contain information about:

- Operating system events
- Hardware problems
- Service status

---

## Authentication Logs

Track:

- Login attempts
- User access
- Failed passwords
- Account changes

---

## Application Logs

Record:

- Application errors
- User actions
- Service activities

---

## Network Logs

Monitor:

- Connections
- Firewall events
- Network traffic

---

# 4. Log Management Best Practices

Follow these practices:

- Enable logging on important systems
- Protect log files from modification
- Store logs securely
- Review logs regularly
- Remove unnecessary old logs

---

# 5. Monitoring Tools

Examples of monitoring tools:

- System performance monitors
- Network monitoring tools
- Log analysis tools
- Security information and event management (SIEM) systems

---

# 6. Detecting Suspicious Activities

Look for:

- Multiple failed login attempts
- Login from unknown locations
- Unexpected system changes
- Unusual network traffic
- New unknown user accounts

---

# 7. Protecting Log Data

Security controls:

- Restrict log access
- Use encryption
- Create backup copies
- Monitor log changes

---

# 8. Regular Security Reviews

Perform regular checks:

- Review system logs
- Analyze security alerts
- Update monitoring rules
- Investigate unusual events

---

# Conclusion

Monitoring and logging help administrators maintain system security, identify threats, and respond quickly to incidents.

Proper monitoring improves visibility and strengthens overall system protection.
